O que o ClusterBasedNormalizer faz internamente

Processo interno de ajuste do GMM
1. Recebe valores da coluna: [12450, 35800, -230.5, 67200, 4100.75]
2. Executa sklearn.mixture.BayesianGaussianMixture(n_components=5)
3. BayesianGMM remove modos com peso < threshold (0.005)
4. Resultado: 2 modos válidos permanecem (outros foram removidos)

Parâmetros ajustados:
Modo 0: μ₀=1,935, ϕ₀=2,345, peso=0.60, n_amostras=3
Modo 1: μ₁=38,483, ϕ₁=14,912, peso=0.40, n_amostras=2

Como funciona a atribuição de modo para cada valor

Artigo § 4.2 — probabilidade do modo k para o valor c
P(Cᵢ = k | c) = μₖ · N(c; ηₖ, ϕₖ) / Σⱼ μⱼ · N(c; ηⱼ, ϕⱼ)

N(c; η, ϕ) = (1 / (ϕ√(2π))) · exp(−(c − η)² / (2ϕ²))

Linha 1: c = 12,450
  N(12450; 1935, 2345) = (1/(2345×2.507)) × exp(−(12450−1935)²/(2×2345²))
  = (1/5879) × exp(−(10515)²/11004050)
  = (1/5879) × exp(−10.04)
  = (1/5879) × 0.0000435 = 7.40e-9

  N(12450; 38483, 14912) = (1/(14912×2.507)) × exp(−(12450−38483)²/(2×14912²))
  = (1/37386) × exp(−(−26033)²/444729728)
  = (1/37386) × exp(−1.516)
  = (1/37386) × 0.2195 = 5.87e-6

ρ₀ = (0.60 × 7.40e-9) / (0.60 × 7.40e-9 + 0.40 × 5.87e-6)
  = 4.44e-9 / (4.44e-9 + 2.35e-6) = 0.00189
ρ₁ = 0.99811

→ Amostra de [0.00189, 0.99811] → Modo 1 (saldo alto)
Mas na prática, sklearn usa hard assignment via argmax → Linha 1 → Modo 0 (cluster saldo baixo)
A discrepância: sklearn usa EM para atribuição dura, não amostragem. Linhas 1,3,5 se agrupam como "baixo".

def sample_condvec(self, batch):      # batch = 500
    # Passo 1: seleciona coluna discreta (probabilidade igual)

        np.arange(self._n_discrete_columns), batch  # [0,1] → seleciona aleatoriamente
    )

class Generator(Module):
    def __init__(self, embedding_dim, generator_dim, data_dim):
        # embedding_dim = 128 + 5 = 133 (ruído + condição)
        # generator_dim = (256, 256)
        # data_dim = 10 (largura da matriz codificada)
        dim = embedding_dim    # 133
        seq = []
        for item in list(generator_dim):   # [256, 256]
            seq += [Residual(dim, item)]   # Residual(133, 256), depois Residual(389, 256)
            dim += item                    # 133+256=389, depois 389+256=645
        seq.append(Linear(dim, data_dim))  # Linear(645, 10)
        self.seq = Sequential(*seq)

5b Bloco Residual — operações reais ▸ 
# ctgan.py:65-79
class Residual(Module):
    def __init__(self, i, o):
        self.fc = Linear(i, o)       # ex: Linear(133, 256)
        self.bn = BatchNorm1d(o)     # BatchNorm1d(256)
        self.relu = ReLU()

    def forward(self, input_):
        out = self.fc(input_)        # (batch, 133) → (batch, 256)
        out = self.bn(out)           # normaliza pelo batch
        out = self.relu(out)         # max(0, x)
        return torch.cat([out, input_], dim=1)  # (batch, 256+133=389)
Exemplo numérico — Linha 1 do batch
input_ = [−0.21, 0.85, ..., 0.33] (133 valores: 128 de ruído + 5 de condição)

FC₁₃₃→₂₅₆:
  out[j] = Σᵢ (input_[i] × W[j,i] + b[j])  para j = 0..255
  W forma: (256, 133), b forma: (256,)
  Exemplo: out[0] = input_[0]×W[0,0] + input_[1]×W[0,1] + ... + input_[132]×W[0,132] + b[0]

BN₂₅₆:
  out[j] = γⱼ × (out[j] − μ_batch) / √(σ²_batch + ε) + βⱼ
  onde γ, β são aprendíveis, μ, σ são estatísticas do batch

ReLU:
  out[j] = max(0, out[j])

cat:
  result = [out[0], ..., out[255], input_[0], ..., input_[132]] ← 389 valores
5c _apply_activate() — tanh e gumbel_softmax ▸ 
# ctgan.py:221-239
def _apply_activate(self, data):
    data_t = []
    st = 0
    for column_info in self._transformer.output_info_list:
        for span_info in column_info:
            if span_info.activation_fn == 'tanh':
                ed = st + span_info.dim
                data_t.append(torch.tanh(data[:, st:ed]))   # escalares α
                st = ed
            elif span_info.activation_fn == 'softmax':
                ed = st + span_info.dim
                transformed = self._gumbel_softmax(data[:, st:ed], tau=0.2)
                data_t.append(transformed)                   # categorias β
                st = ed
    return torch.cat(data_t, dim=1)

Passo 6 — Discriminador + Perda

6a Discriminador com PacGAN ▸ 
# ctgan.py:22-33 — Discriminator
class Discriminator(Module):
    def __init__(self, input_dim, discriminator_dim, pac=10):
        dim = input_dim * pac    # (10+5) × 10 = 150
        self.pac = pac           # 10
        seq = []
        for item in list(discriminator_dim):  # [256, 256]
            seq += [Linear(dim, item), LeakyReLU(0.2), Dropout(0.5)]
            dim = item
        seq += [Linear(dim, 1)]  # 256 → 1
        self.seq = Sequential(*seq)

    def forward(self, input_):
        assert input_.size()[0] % self.pac == 0
        return self.seq(input_.view(-1, self.pacdim))  # reshape para PacGAN
PacGAN — como 10 linhas são empacotadas
Batch real: 10 linhas de [data(10) + cond(5)] = 10 × 15 = 150 valores
PacGAN empacota: input_.view(-1, 150) → (batch/10, 150)

Isso significa que o discriminador vê 10 linhas REAIS ou 10 FALSAS ao mesmo tempo,
ajudando-o a distinguir colapso de modos (todas as linhas falsas parecem iguais).
Penalidade de gradiente WGAN-GP ctgan.py:35-57
alpha = rand(batch//10, 1, 1) → repete para (batch, 1, 15) → view (batch, 150)
interpolates = alpha × real + (1−alpha) × fake   ← amostras interpoladas
disc_interpolates = self(interpolates)
gradients = autograd.grad(disc_interpolates, interpolates)
gradient_penalty = (‖gradients‖₂ − 1)² × λ   onde λ=10

Perda D: L_D = E[C(x_real)] − E[C(x_fake)] + λ · GP
  onde C = criticador, GP = penalidade de gradiente

Perda G: L_G = −E[C(x_fake)] + CrossEntropy(G(z,cond)_condição, condição)
  primeiro termo: enganar o discriminador
  segundo termo: respeitar o vetor condicional
⬇

def _inverse_transform_discrete(self, column_transform_info, column_data):

    return ohe.reverse_transform(data)[column_transform_info.column_name]
