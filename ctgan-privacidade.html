Resumo Executivo

Modelos generativos para dados tabulares como CTGAN (GAN) e TVAE (VAE) possuem risco intrínseco de vazamento de dados. Ambos podem memorizar padrões dos dados de treino e reproduzi-los em dados sintéticos, expondo informações sensíveis.

Mecanismos de Vazamento

Existem três principais mecanismos pelos quais CTGAN e TVAE podem vazar dados:

1. Memorização Direta

O modelo pode memorizar registros específicos do treino e reproduzi-los quase idênticos nos dados sintéticos. Isso é mais comum em GANs (CTGAN) onde o discriminador pode causar overfitting.

2. Membership Inference Attacks (MIA)

Atacantes podem determinar se um registro específico estava no conjunto de treino, mesmo sem acesso ao modelo. Métricas como AUC medem essa vulnerabilidade.

3. Cluster Overlap

Mesmo sem memorização direta, os dados sintéticos formam clusters que se alinham com os clusters dos dados reais. Atacantes podem detectar essa sobreposição e inferir informações sensíveis.

Problema Fundamental: Para gerar dados realistas, o modelo precisa aprender a distribuição dos dados de treino fielmente. Essa fidelidade cria uma "mancha cega" onde a utilidade do modelo entra em conflito com a privacidade.

CTGAN — Riscos Específicos

Mecanismo de Vazamento

O CTGAN usa uma GAN (Generative Adversarial Network) com dois componentes: Generator e Discriminator. O Discriminator pode causar overfitting ao memorizar características específicas dos dados de treino para distinguir melhor reais de falsos.

Especificidade do CTGAN: Em um estudo, CTGAN treinado com um registro específico produziu dados com o valor "Holland-Netherlands" em 92% dos casos, enquanto modelos não treinados com esse registro nunca o produziam.

TVAE — Riscos Específicos

Mecanismo de Vazamento

O TVAE usa um VAE (Variational Autoencoder) com Encoder e Decoder. O Encoder aprende a comprimir dados em um espaço latente probabilístico. Os códigos latentes podem codificar padrões específicos dos dados de treino, permitindo reconstrução parcial.

Diferença do CTGAN: Enquanto CTGAN memoriza via competição adversarial, TVAE memoriza via codificação latente. TVAE tende a ter menor risco que CTGAN em maioria dos estudos, mas ainda significativo.

2025 · arXiv:2507.17066 (submetido)

Avalia CTGAN, TVAE, TabDiff e foundation models (GPT-4o, LLaMA) em 35 datasets reais.

Resultado: CTGAN: AUC 0.580, TVAE: AUC 0.580–0.627. Foundation models têm maior risco (0.587–0.667). CTGAN e GPT-4o-mini oferecem melhor trade-off qualidade/privacidade.

Mitigações

1. Differential Privacy (DP)

Adicionar ruído calibrado durante o treino para limitar o impacto de cada registro individual.

Exemplo: PATE-GANDP-GAN
# PATE-GAN usa Differential Privacy para proteger dados
# O ruído é adicionado durante o treino do discriminador
# Isso limita a memorização, mas reduz qualidade

# Trade-off fundamental:
# Mais DP → Mais privacidade → Menos utilidade
# Menos DP → Menos privacidade → Mais utilidade

2. Limitar Epochs de Treino

Parar o treino antes do modelo memorizar os dados.

3. Validação com MIA

Testar o modelo com Membership Inference Attacks antes de liberar dados.

4. Não Liberar o Modelo

Release apenas dados sintéticos, nunca os pesos do modelo.

Recomendação: Para dados sensíveis (saúde, finanças), use obrigatoriamente Differential Privacy. A perda de qualidade é o custo da privacidade.

Para Dados Não-Sensíveis

  • CTGAN ou TVAE são aceitáveis
  • Validar com MIA antes de liberar
  • Não liberar o modelo treinado

Para Dados Sensíveis (Saúde, Finanças)

  • Usar obrigatoriamente Differential Privacy
  • Considerar PATE-GAN ou DP-GAN
  • Aceitar perda de qualidade como custo
  • Realizar auditoria de privacidade completa
Aviso: Nenhum modelo generativo é 100% seguro sem proteções formais. Differential Privacy é a única garantia matemática de privacidade disponível.
