O que é TVAE

O TVAE (Tabular Variational Autoencoder) é um modelo generativo baseado em Variational Autoencoder (VAE) projetado especificamente para gerar dados tabulares sintéticos com tipos mistos (numéricos e categóricos).

Paper Original

"To further challenge CTGAN, we adapt a variational autoencoder (VAE) for mixed-type tabular data generation. We call this TVAE. VAEs directly use data to build the generator; even with this advantage, we show that our proposed CTGAN achieves competitive performance across many datasets."

— Xu et al., NeurIPS 2019

Princípio Fundamental

Enquanto o CTGAN usa uma GAN (Generator + Discriminator competindo), o TVAE usa um Autoencoder Variacional que aprende uma representação latente probabilística dos dados, permitindo gerar novas amostras a partir dessa distribuição.

Ideia Central: O VAE mapeia os dados de entrada para uma distribuição probabilística no espaço latente (não apenas um vetor fixo como autoencoders tradicionais), permitindo amostrar novos pontos e decodificá-los para gerar dados sintéticos.

Arquitetura do TVAE

O TVAE consiste em duas redes neurais principais: um Encoder que mapeia dados para o espaço latente, e um Decoder que reconstrói dados a partir do espaço latente.

Diferença do Autoencoder Tradicional: Um autoencoder comum mapeia o input para um vetor fixo no espaço latente. O VAE mapeia para uma distribuição (μ, σ), permitindo amostrar pontos aleatórios e gerar dados novos.

Encoder — q(z|r)

O Encoder é uma rede neural que mapeia os dados de entrada para parâmetros de uma distribuição Gaussiana no espaço latente.

Paper Original

"In TVAE, we use two neural networks to model pθ(rj|zj) and qφ(zj|rj), and train them using evidence lower-bound (ELBO) loss."

— Xu et al., NeurIPS 2019

Arquitetura do Encoder

Arquitetura do Encoder (paper original)PyTorch
# Encoder: mapeia input → (μ, σ)
# Camadas:
h1 = ReLU(FC(|rj| → 128)(rj))      # Input → 128
h2 = ReLU(FC(128 → 128)(h1))       # 128 → 128
μ  = FC(128 → 128)(h2)             # 128 → 128 (média)
σ  = exp(½ · FC(128 → 128)(h2))    # 128 → 128 (desvio padrão)

# Distribuição latente
qφ(zj|rj) ~ N(μ, σI)

O que o Encoder faz

  • Recebe os dados tabulares (numéricos + categóricos codificados)
  • Passa por camadas totalmente conectadas com ativação ReLU
  • Gera dois vetores: μ (média) e σ (desvio padrão)
  • Esses vetores definem uma distribuição Gaussiana no espaço latente
Reparameterization Trick: Para permitir backpropagation, o VAE usa o truque de reparametrização: z = μ + σ · ε, onde ε ~ N(0, 1). Isso torna a amostragem diferenciável.

Decoder — p(r|z)

O Decoder é uma rede neural que mapeia pontos do espaço latente de volta para o espaço original dos dados.

Arquitetura do Decoder

Arquitetura do Decoder (paper original)PyTorch
# Decoder: mapeia latente → output
# Camadas:
h1 = ReLU(FC(128 → 128)(z))         # Latente → 128
h2 = ReLU(FC(128 → 128)(h1))       # 128 → 128
r̂  = FC(128 → |rj|)(h2)            # 128 → Output

# Saída: dados reconstruídos (ou sintéticos)

O que o Decoder faz

  • Recebe um vetor z amostrado da distribuição latente
  • Passa por camadas totalmente conectadas com ativação ReLU
  • Gera a reconstrução dos dados (ou dados sintéticos)
  • Para dados numéricos: saída linear
  • Para dados categóricos: saída com softmax
Geração de Dados: Para gerar dados sintéticos, basta amostrar z ~ N(0, I) (distribuição padrão) e passar pelo Decoder. O resultado são dados sintéticos que seguem a distribuição dos dados de treinamento.

Loss Function — ELBO

O TVAE é treinado minimizando a ELBO (Evidence Lower Bound) loss, que combina dois termos: reconstrução e divergência KL.

Fórmula ELBO

L_VAE(θ, φ) = -E_{z~qφ(z|x)}[log(pθ(x|z))] + D_KL(qφ(z|x) || p(z))

— Kingma & Welling, 2013

Os Dois Termos

Termo Nome O que faz Objetivo
Reconstrução -E[log(pθ(x|z))] Mede quão bem o Decoder reconstrói os dados Minimizar erro de reconstrução
KL Divergence D_KL(qφ(z|x) || p(z)) Força o espaço latente a ser Gaussiano Regularizar o espaço latente

Intuição

  • Reconstrução: "Os dados gerados parecem com os reais?"
  • KL Divergence: "O espaço latente é bem comportado?"
Trade-off: Se apenas minimizarmos a reconstrução, o modelo pode "decorar" os dados sem aprender uma representação útil. O termo KL força o espaço latente a ser contínuo e organizado, permitindo generalização.

Processo de Treinamento

O treinamento do TVAE é mais simples e estável que o CTGAN, pois envolve apenas uma rede neural (não duas competindo como em GANs).

Algoritmo de Treinamento

Treinamento TVAE (simplificado)Pseudocódigo
# Para cada batch de dados reais:
for batch in dataloader:

    # 1. Encoder: mapear dados para distribuição latente
    μ, σ = encoder(batch)

    # 2. Amostrar do espaço latente (reparameterization trick)
    ε = random_normal(shape=μ.shape)
    z = μ + σ * ε

    # 3. Decoder: reconstruir dados a partir de z
    reconstrução = decoder(z)

    # 4. Calcular loss
    loss_reconstrução = MSE(batch, reconstrução)
    loss_kl = D_KL(N(μ, σI) || N(0, I))
    loss = loss_reconstrução + loss_kl

    # 5. Backpropagation
    loss.backward()
    optimizer.step()

Por que é mais rápido? O CTGAN treina duas redes neurais (Generator + Discriminator) alternadamente, com mais forward/backward passes. O TVAE treina apenas uma rede (Encoder + Decoder), com uma loss function única e convergência mais estável.

Simulação: Como o TVAE Gera Dados

Passo a passo de como o TVAE gera dados sintéticos após o treinamento.

Exemplo: Dataset de Clientes Bancários

Dados Originais5 registros
 idade  salario   estado_civil Score
   25    3500.0      Solteiro     720
   35    7500.0      Casado       680
   45   12000.0      Casado       750
   30    5000.0      Solteiro     700
   50   15000.0      Divorciado   800

Passo 1: Encoder (Dados → Latente)

Encoder processa cada registroExemplo: registro 1 (idade=25, salario=3500)
# Input normalizado
r = [0.25, 0.23, 1.0, 0.72]  # idade, salario, civil, score

# Encoder calcula μ e σ
h1 = ReLU(FC(4 → 128)(r))     # [0.82, 0.15, ...] (128 valores)
h2 = ReLU(FC(128 → 128)(h1))  # [0.45, 0.91, ...] (128 valores)
μ  = FC(128 → 128)(h2)        # [-0.5, 0.3, ...] (128 valores)
σ  = exp(½ · FC(128 → 128)(h2))  # [0.8, 1.2, ...] (128 valores)

# Espaço latente: z ~ N(μ, σI)
ε = [0.1, -0.5, 0.8, ...]     # amostra de N(0, 1)
z = μ + σ * ε                  # [-0.42, -0.3, ...]

Passo 2: Decoder (Latente → Dados)

Decoder reconstrói os dadosA partir de z
# Decoder processa z
h1 = ReLU(FC(128 → 128)(z))    # [0.65, 0.28, ...]
h2 = ReLU(FC(128 → 128)(h1))   # [0.42, 0.71, ...]
r̂  = FC(128 → 4)(h2)           # [0.24, 0.22, 0.98, 0.71]

# Output desnormalizado
idade ≈ 24, salario ≈ 3400, civil ≈ Solteiro, score ≈ 715

Passo 3: Geração de Dados Sintéticos

Gerando dados novosApós treinamento
# Amostrar z da distribuição padrão (N(0, I))
z_novo = [-0.3, 0.5, -0.1, 0.8, ...]  # 128 valores

# Passar pelo Decoder
dados_sintéticos = decoder(z_novo)

# Resultado:
# idade=32, salario=6800, civil=Casado, score=710
# (novo registro que não existia nos dados originais!)
Resultado: O TVAE aprendeu a distribuição dos dados bancários e pode gerar infinitos registros sintéticos que mantêm as relações estatísticas dos dados originais.

Quando Usar TVAE

Use TVAE quando:

  • Velocidade é prioridade — TVAE é ~3x mais rápido
  • Memória é limitada — TVAE usa ~40% menos memória
  • Treinamento estável — convergência mais previsível
  • Dados simples a moderados — distribuições não muito complexas
  • Muitas épocas necessárias — overhead menor por época

Use CTGAN quando:

  • Amostragem condicional — gerar dados com condições específicas
  • Distribuições multimodais — dados com múltiplos picos
  • Dados muito complexos — relações não-lineares intrincadas
  • Qualidade máxima — quando a velocidade não é crítica

Decisão Rápida

TVAE
Velocidade + Estabilidade

Dica: Comece com TVAE (mais rápido). Se a qualidade não for satisfatória, experimente CTGAN. Para maioria dos casos de uso, TVAE é suficiente.
