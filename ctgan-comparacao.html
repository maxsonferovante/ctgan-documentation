    condition_column='Score',
    condition_value='Alto'

# Resultado: todos os registros com Score > 700
Limitação do TVAE: O TVAE não suporta amostragem condicional. Se você precisa gerar dados com condições específicas, o CTGAN é a escolha única.

Casos de Uso

Use CTGAN quando:

CTGAN Amostragem Condicional

Precisa gerar dados com condições específicas (ex: apenas clientes com Score > 700, apenas transações > R$ 1000).

CTGAN Dados Multimodais Complexos

Dados com múltiplos picos (ex: salários com modos em R$ 2000, R$ 5000, R$ 15000). CTGAN trata cada modo separadamente.

CTGAN Dados Muito Desbalanceados

Colunas categóricas com categorias raras (ex: "ouro" em programa de fidelidade com 0.1% dos clientes). CTGAN balanceia automaticamente.

CTGAN Qualidade Máxima

Quando a qualidade dos dados sintéticos é mais importante que velocidade. CTGAN gera dados estatisticamente mais fiéis.

Use TVAE quando:

TVAE Velocidade É Prioridade

Precisa gerar dados rapidamente (ex: protótipos, testes, pipelines de dados). TVAE é ~3x mais rápido.

TVAE Memória Limitada

Executando em máquinas com pouca RAM (ex: notebooks, containers). TVAE usa ~40% menos memória.

TVAE Treinamento Estável

Precisa de convergência previsível sem tuning excessivo. TVAE é mais estável e fácil de usar.

TVAE Dados Simples a Moderados

Dados com distribuições relativamente simples. TVAE é suficiente e mais eficiente.

Ambos Podem Ser Usados:

AMBOS Dados Tabulares Gerais

Para maioria dos datasets tabulares. Comece com TVAE (mais rápido), teste CTGAN se precisar de mais qualidade.

AMBOS Privacidade de Dados

Ambos geram dados sintéticos que preservam estatísticas sem expor dados reais. Útil para compartilhamento seguro.

AMBOS Aumento de Dados

Ambos podem aumentar datasets para treinar modelos de ML, especialmente quando dados reais são escassos.

AMBOS Testes de Software

Ambos geram dados realistas para testes de sistemas, APIs e bancos de dados.

Árvore de Decisão

Use esta árvore para escolher entre CTGAN e TVAE:

Você precisa de amostragem condicional?
Gerar dados com condições específicas (ex: Score > 700)?
SIM → CTGAN
O CTGAN é o único que suporta amostragem condicional nativamente.
NÃO → Prosseguir...
Velocidade é prioridade?
Precisa treinar rapidamente ou tem muitos dados?
SIM → TVAE
TVAE é ~3x mais rápido e usa menos memória.
NÃO → Prosseguir...
Os dados têm distribuições multimodais complexas?
Múltiplos picos, padrões não-lineares intrincados?
SIM → CTGAN
CTGAN é melhor para dados complexos.
NÃO → TVAE
TVAE é suficiente e mais eficiente.
Regra Simples: Comece sempre com TVAE. Mude para CTGAN apenas se precisar de amostragem condicional ou se a qualidade não for satisfatória.

Fluxo de Decisão Recomendado

Algoritmo de EscolhaPython-like
def escolher_modelo(necessita_condicional, dados_complexos, prioridade_velocidade):
    """Escolhe entre CTGAN e TVAE baseado nos requisitos."""
    if necessita_condicional:
        return "CTGAN"
    if prioridade_velocidade:
        return "TVAE"
    if dados_complexos:
        return "CTGAN"
    return "TVAE"  # Padrão

# Exemplos:
print(escolher_modelo(True, False, False))   # CTGAN (condicional)
print(escolher_modelo(False, False, True))   # TVAE (velocidade)
print(escolher_modelo(False, True, False))   # CTGAN (complexo)
print(escolher_modelo(False, False, False))  # TVAE (padrão)
Resumo: TVAE é a escolha padrão para maioria dos casos. CTGAN só é necessário quando você precisa de amostragem condicional ou quando os dados são extremamente complexos e desbalanceados.
