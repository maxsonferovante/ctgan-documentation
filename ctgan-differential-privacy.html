Resumo Executivo

Differential Privacy (DP) é a única garantia matemática de privacidade para modelos generativos. Existem duas abordagens principais para implementar DP em CTGAN/TVAE:

RECOMENDADA dpsdg

Biblioteca pronta para uso com DP-CTGAN e DP-TVAE. API quase idêntica ao CTGAN original.

GitHub: brains-group/dpsdg

ALTERNATIVA Opacus

Biblioteca PyTorch para DP-SGD manual. Mais flexível, mas requer mais trabalho de integração.

GitHub: meta-pytorch/opacus

Opção 1: dpsdg (Recomendada)

O que é

Implementação oficial de DP-CTGAN e DP-TVAE que estende a biblioteca CTGAN com treinamento diferencialmente privado via DP-SGD. A API é quase idêntica ao CTGAN original, facilitando a migração.

git clone https://github.com/brains-group/dpsdg.git

DP-CTGAN

dp_ctgan.pyPython
import pandas as pd
from dpsdg.models.dp_ctgan import DPDPCTGAN

# Seus dados
real_data = pd.DataFrame({
    'idade': [25, 30, 35, 40, 45],
    'salario': [3000, 5000, 7000, 9000, 12000],
    'risco': ['baixo', 'medio', 'alto', 'medio', 'baixo']
})
discrete_columns = ['risco']

# CTGAN original (sem privacidade)
from ctgan import CTGAN
ctgan = CTGAN(epochs=300)
ctgan.fit(real_data, discrete_columns)
synthetic = ctgan.sample(1000)

# DP-CTGAN (com privacidade)
model = DPDPCTGAN(
    epsilon=1.0,        # Budget de privacidade
    delta=1e-5,          # Probabilidade de falha
    epochs=300
)

# OBRIGATÓRIO: chamar fit_transformer antes do fit
model.fit_transformer(real_data, discrete_columns)

# Treinar normalmente
model.fit(real_data, discrete_columns)

# Gerar dados sintéticos
synthetic = model.sample(1000)
Atenção: O DP-CTGAN requer a chamada fit_transformer() antes do fit(). Isso configura o transformador de dados ciente de privacidade. Sem isso, o modelo não terá garantias de DP.

Parâmetros de Privacidade

Parâmetro Tipo Default Descrição
epsilon float 0.0 (CTGAN) / 1.0 (TVAE) Budget de privacidade (ε). Menor = mais privacidade
delta float 1e-5 Probabilidade de falha (δ). Deve ser << 1/n
max_grad_norm float 1.0 Threshold de clipping para gradientes

Valores de Epsilon Recomendados

Epsilon (ε) Privacidade Qualidade Uso Recomendado
0.1 Muito forte Muito baixa Dados extremamente sensíveis
1.0 Forte Moderada Saúde, finanças (padrão)
5.0 Moderada Boa Dados sensíveis gerais
10.0 Fraca Alta Dados semi-sensíveis

Opção 2: Opacus (Alternativa)

O que é

Biblioteca PyTorch do Meta para treinar modelos com Differential Privacy usando DP-SGD. Mais flexível que dpsdg, mas requer mais trabalho de integração com CTGAN/TVAE.

Instalação

Terminalpip
pip install opacus

Como Funciona

O Opacus modifica o processo de treinamento padrão com três etapas:

  1. Gradient Clipping: Limita a norma L2 de cada gradiente individual
  2. Noise Addition: Adiciona ruído gaussiano calibrado aos gradientes
  3. Privacy Accounting: Calcula o budget de privacidade consumido

Integração com CTGAN

opacus_ctgan.pyPython
import torch
from torch.optim import SGD
from opacus import PrivacyEngine
from ctgan import CTGAN

# Criar modelo CTGAN
ctgan = CTGAN(epochs=300)

# Criar Privacy Engine
privacy_engine = PrivacyEngine()

# Transformar dados (exemplo simplificado)
# Na prática, você precisa acessar os componentes internos do CTGAN

# O Opacus precisa de:
# 1. O modelo PyTorch (discriminator ou generator)
# 2. Um optimizer
# 3. Um DataLoader

# Exemplo conceitual:
model, optimizer, data_loader = privacy_engine.make_private(
    module=ctgan.discriminator,  # Componente a ser protegido
    optimizer=optimizer,
    data_loader=data_loader,
    noise_multiplier=1.1,        # Razão ruído/gradiente
    max_grad_norm=1.0,           # Threshold de clipping
)

# Treinar normalmente — gradientes já são perturbados
ctgan.fit(data, discrete_columns)
Atenção: A integração do Opacus com CTGAN não é trivial. O CTGAN tem arquitetura interna complexa (generator + discriminator + training loop). Você precisará modificar o código-fonte do CTGAN para usar Opacus corretamente.

Parâmetros do Opacus

Parâmetro Tipo Default Descrição
noise_multiplier float 1.1 Razão entre ruído e gradiente clipado
max_grad_norm float 1.0 Threshold de clipping para gradientes
target_epsilon float Opcional Budget de privacidade alvo
target_delta float Opcional Probabilidade de falha alvo

Parâmetros de Privacidade em Detalhe

Epsilon (ε)

O parâmetro mais importante. Define o "budget" de privacidade. Um valor menor significa que o modelo revelation menos sobre qualquer registro individual do treino.

Interpretação de EpsilonConceitual
# Epsilon = 1.0 significa:
# "A probabilidade de o modelo agir diferente com/sem
#  qualquer registro individual é limitada por factor e^ε = 2.718"

# Epsilon = 0.1 significa:
# "O modelo é quase idêntico com ou sem qualquer registro"
# → Máxima privacidade, mas dados de baixa qualidade

# Epsilon = 10.0 significa:
# "O modelo pode diferir significativamente"
# → Menos privacidade, mas dados de alta qualidade

Delta (δ)

Probabilidade de que a garantia de privacidade falhe. Deve ser extremamente pequena — tipicamente 1/n onde n é o número de registros de treino.

Cálculo de DeltaPython
# Para 10.000 registros de treino:
n = 10000
delta = 1 / (n * 10)  # = 1e-5 (muito menor que 1/n)

# Para 1.000 registros:
n = 1000
delta = 1 / (n * 10)  # = 1e-4

# Regra geral: delta << 1/n

Max Grad Norm

Threshold de clipping. Limita quanto cada registro individual pode influenciar o gradiente. Um valor menor = mais privacidade, mas converge mais devagar.

Exemplo de ClippingConceitual
# Gradiente original: [0.5, 1.2, 0.8, 2.1]
# max_grad_norm = 1.0

# Norma L2 = sqrt(0.5² + 1.2² + 0.8² + 2.1²) = 2.58
# Fator de escala = min(1.0 / 2.58, 1.0) = 0.387

# Gradiente clipado: [0.19, 0.46, 0.31, 0.81]

Exemplos Práticos

Caso 1: Dados de Saúde (Privacidade Máxima)

saude_dp.pyPython
import pandas as pd
from dpsdg import DPTVAE

# Dados médicos sensíveis
dados_saude = pd.DataFrame({
    'idade': [45, 52, 38, 61, 29],
    'pressao': [140, 160, 120, 180, 110],
    'colesterol': [250, 280, 200, 300, 180],
    'diabetico': ['sim', 'sim', 'nao', 'sim', 'nao']
})
discrete_columns = ['diabetico']

# Privacidade máxima para dados de saúde
model = DPTVAE(
    epsilon=1.0,        # Budget forte
    delta=1e-5,         # Falha extremamente improvável
    epochs=300
)

model.fit(dados_saude, discrete_columns)
dados_sinteticos = model.sample(5000)

# Resultado: dados sintéticos com garantia matemática de privacidade

Trade-off Qualidade vs Privacidade

Trade-offConceitual
# Cenário: 10.000 registros de clientes bancários

# ε = 0.1 (Privacidade Máxima)
# → Dados muito ruidosos
# → Estatísticas pouco fiéis
# → ML models com accuracy ~50%
# → Ideal para: dados ultra-sensíveis (HIV, HIV+)

# ε = 1.0 (Privacidade Forte)
# → Dados moderadamente ruidosos
# → Estatísticas razoavelmente fiéis
# → ML models com accuracy ~70%
# → Ideal para: dados de saúde, finanças

# ε = 5.0 (Privacidade Moderada)
# → Dados pouco ruidosos
# → Estatísticas fiéis
# → ML models com accuracy ~85%
# → Ideal para: dados corporativos

# ε = 10.0 (Privacidade Fraca)
# → Dados quase originais
# → Estatísticas muito fiéis
# → ML models com accuracy ~90%+
# → Ideal para: dados semi-públicos
Regra de Ouro: Não existe "tamanho único". O valor de ε deve ser escolhido com base na sensibilidade dos dados e nos requisitos de uso. Para dados de saúde, ε=1.0 é recomendado. Para dados financeiros, ε=5.0 pode ser suficiente.

Para o Branch Polars

integracao_polars.pyPython
# O dpsdg espera pandas DataFrame como entrada
# Nosso código usa Polars DataFrame

# Solução: converter Polars → Pandas para treino com DPSDG

import polars as pl
import pandas as pd
from dpsdg import DPTVAE

# Dados em Polars
df_polars = pl.DataFrame({
    'idade': [25, 30, 35, 40, 45],
    'salario': [3000, 5000, 7000, 9000, 12000],
    'risco': ['baixo', 'medio', 'alto', 'medio', 'baixo']
})

# Converter para Pandas
df_pandas = df_polars.to_pandas()

# Treinar com DPSDG
model = DPTVAE(epsilon=1.0, delta=1e-5, epochs=300)
model.fit(df_pandas, discrete_columns=['risco'])
dados_sinteticos = model.sample(1000)

# Converter de volta para Polars (se necessário)
df_sintetico_polars = pl.from_pandas(dados_sinteticos)
