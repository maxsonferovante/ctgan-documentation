Resumo

Modelar a distribuição de probabilidade das linhas em dados tabulares e gerar dados sintéticos realistas não é uma tarefa trivial. Dados tabulares geralmente contêm uma mistura de colunas discretas e contínuas. Colunas contínuas podem ter múltiplos modos, enquanto colunas discretas são frequentemente desbalanceadas, tornando a modelagem difícil.

Modelos estatísticos e de redes neurais existentes não conseguem modelar adequadamente esse tipo de dado. O CTGAN utiliza um gerador condicional para resolver esses desafios, e o TVAE adapta um autoencoder variacional para o mesmo propósito.

O CTGAN supera métodos bayesianos na maioria dos datasets reais e ultrapassa baselines de deep learning em pelo menos 87,5% dos datasets avaliados.

5 Desafios Principais

A Seção 3 do artigo identifica cinco desafios únicos ao aplicar GANs à geração de dados tabulares:

1

Tipos de Dados Mistos

Dados tabulares do mundo real consistem em tipos mistos. GANs devem aplicar softmax e tanh na saída para gerar simultaneamente colunas discretas e contínuas.

2

Distribuições Não-Gaussianas

Em imagens, os pixels seguem uma distribuição semelhante à Gaussiana. Valores contínuos em dados tabulares são geralmente não-Gaussianos, onde a transformação min-max leva ao problema de gradiente que desaparece.

3

Distribuições Multimodais

57 das 123 colunas contínuas nos 8 datasets reais possuem múltiplos modos. Uma GAN simples não consegue modelar todos os modos em um dataset 2D básico.

4

Aprendizado com Vetores One-Hot Esparsos

Um discriminador simples pode distinguir dados reais e falsos verificando a esparsidade da distribuição, em vez de considerar a autenticidade geral de uma linha.

5

Colunas Categóricas Altamente Desbalanceadas

636 das 1048 colunas categóricas são altamente desbalanceadas (categoria majoritária > 90%). Isso cria um colapso de modos severo.

Normalização por Modos

Artigo § 4.2 Cada coluna contínua é modelada usando um Modelo de Mistura Gaussiana Variacional. Cada valor é decomposto em um vetor one-hot indicando o modo e um escalar indicando o valor dentro desse modo: αᵢ,ⱼ = (cᵢ,ⱼ − ηₛ) / (4ϕₛ) normalizado para [−1, 1] via tanh. — Xu et al., § 4.2 Mode-specific Normalization

Por que não Min-Max simples?

A normalização min-max colapsa todos os valores contínuos em um único modo, apagando a estrutura multi-modal. A normalização por modos usa um Modelo de Mistura Gaussiana (GMM) para descobrir modos, e depois representa cada valor como (modo, valor-dentro-do-modo).

Os Três Passos

  1. Ajustar GMM: Usar uma Mistura Gaussiana Variacional para estimar o número de modos m e seus parâmetros (μ, η, ϕ).
  2. Calcular probabilidades dos modos: Para cada valor, calcular ρₖ = μₖ · N(cᵢ,ⱼ; ηₖ, ϕₖ).
  3. Amostrar e codificar: Amostrar um modo da densidade de probabilidade, produzir one-hot β e escalar α = tanh((c − η) / (4ϕ)).

def _fit_continuous(self, data):
    column_name = data.columns[0]
    gm = ClusterBasedNormalizer(
        missing_value_generation='from_column',
        max_clusters=min(len(data), self._max_clusters),
        weight_threshold=self._weight_threshold,
    )
    gm.fit(data, column_name)
    num_components = sum(gm.valid_component_indicator)

    return ColumnTransformInfo(
        column_name=column_name,
        column_type='continuous',
        transform=gm,
        output_info=[
            SpanInfo(1, 'tanh'),                    # α — escalar
            SpanInfo(num_components, 'softmax')     # β — one-hot do modo
        ],
        output_dimensions=1 + num_components,
    )

def _transform_continuous(self, column_transform_info, data):
    column_name = data.columns[0]
    flattened_column = data[column_name].to_numpy().flatten()
    data = data.assign(**{column_name: flattened_column})
    gm = column_transform_info.transform
    transformed = gm.transform(data)

    output = np.zeros((len(transformed), column_transform_info.output_dimensions))
    output[:, 0] = transformed[f'{column_name}.normalized'].to_numpy()
    index = transformed[f'{column_name}.component'].to_numpy().astype(int)
    output[np.arange(index.size), index + 1] = 1.0  # one-hot do modo

    return output

Gerador Condicional & Treinamento por Amostragem

Artigo § 4.3 O gerador condicional é treinado amostrando uma coluna discreta com probabilidade igual, e então amostrando um valor da distribuição de log-frequência dessa coluna. O vetor de condição é concatenado à entrada de ruído, e uma perda de entropia cruzada penaliza o gerador quando a condição não é atendida. — Xu et al., § 4.3 Conditional Generator and Training-by-Sampling

Algoritmo de Treinamento por Amostragem

  1. Criar Nd vetores de máscara preenchidos com zeros mᵢ
  2. Selecionar aleatoriamente uma coluna discreta Di* com probabilidade igual
  3. Construir PMF usando a log-frequência de cada categoria
  4. Selecionar aleatoriamente o valor k* de acordo com a PMF
  5. Definir mi*(k*) = 1
  6. Calcular cond = m₁ ⊕ ... ⊕ mNd

Isso garante que cada coluna discreta e categoria seja visitada proporcionalmente, superando o problema do desbalanceamento.

def sample_condvec(self, batch):
    """Gera o vetor condicional para treinamento."""
    if self._n_discrete_columns == 0:
        return None

    # Passo 2: seleciona aleatoriamente uma coluna discreta (probabilidade igual)
    discrete_column_id = np.random.choice(
        np.arange(self._n_discrete_columns), batch
    )

    cond = np.zeros((batch, self._n_categories), dtype='float32')
    mask = np.zeros((batch, self._n_discrete_columns), dtype='float32')
    mask[np.arange(batch), discrete_column_id] = 1

    # Passos 3-4: amostra categoria da PMF de log-frequência
    category_id_in_col = self._random_choice_prob_index(discrete_column_id)
    category_id = (self._discrete_column_cond_st[discrete_column_id]
                   + category_id_in_col)

    # Passo 5: define one-hot no vetor de condição
    cond[np.arange(batch), category_id] = 1

    return cond, mask, discrete_column_id, category_id_in_col

def _cond_loss(self, data, c, m):
    """Calcula a perda de entropia cruzada na coluna discreta fixa."""
    loss = []
    st = 0
    st_c = 0
    for column_info in self._transformer.output_info_list:
        for span_info in column_info:
            if len(column_info) != 1 or span_info.activation_fn != 'softmax':
                st += span_info.dim
            else:
                ed = st + span_info.dim
                ed_c = st_c + span_info.dim
                tmp = functional.cross_entropy(
                    data[:, st:ed],
                    torch.argmax(c[:, st_c:ed_c], dim=1),
                    reduction='none'
                )
                loss.append(tmp)
                st = ed
                st_c = ed_c

    loss = torch.stack(loss, dim=1)
    return (loss * m).sum() / data.size()[0]

class Generator(Module):
    """Gerador para o CTGAN."""

    def __init__(self, embedding_dim, generator_dim, data_dim):
        super(Generator, self).__init__()
        dim = embedding_dim
        seq = []
        for item in list(generator_dim):
            seq += [Residual(dim, item)]
            dim += item                          # skip connection concatena
        seq.append(Linear(dim, data_dim))
        self.seq = Sequential(*seq)

    def forward(self, input_):
        data = self.seq(input_)
        return data

class Residual(Module):
    """Camada residual para o CTGAN."""

    def __init__(self, i, o):
        super(Residual, self).__init__()
        self.fc = Linear(i, o)
        self.bn = BatchNorm1d(o)
        self.relu = ReLU()

    def forward(self, input_):
        out = self.fc(input_)
        out = self.bn(out)
        out = self.relu(out)
        return torch.cat([out, input_], dim=1)  # skip connection

class Discriminator(Module):
    """Discriminador para o CTGAN."""

    def __init__(self, input_dim, discriminator_dim, pac=10):
        super(Discriminator, self).__init__()
        dim = input_dim * pac
        self.pac = pac
        self.pacdim = dim
        seq = []
        for item in list(discriminator_dim):
            seq += [Linear(dim, item), LeakyReLU(0.2), Dropout(0.5)]
            dim = item
        seq += [Linear(dim, 1)]
        self.seq = Sequential(*seq)

    def calc_gradient_penalty(self, real_data, fake_data, device, pac=10, lambda_=10):
        alpha = torch.rand(real_data.size(0) // pac, 1, 1, device=device)
        alpha = alpha.repeat(1, pac, real_data.size(1))
        alpha = alpha.view(-1, real_data.size(1))
        interpolates = alpha * real_data + ((1 - alpha) * fake_data)
        disc_interpolates = self(interpolates)
        gradients = torch.autograd.grad(
            outputs=disc_interpolates, inputs=interpolates,
            grad_outputs=torch.ones(disc_interpolates.size(), device=device),
            create_graph=True, retain_graph=True, only_inputs=True,
        )[0]
        gradients_view = gradients.view(-1, pac * real_data.size(1)).norm(2, dim=1) - 1
        gradient_penalty = (gradients_view ** 2).mean() * lambda_
        return gradient_penalty

Modelo TVAE

Artigo § 4.5 O TVAE adapta o VAE para dados tabulares usando o mesmo pré-processamento do CTGAN. O codificador mapeia os dados para um espaço latente (μ, σ), e o decodificador reconstrói com uma perda modificada que leva em conta tanto saídas contínuas (Gaussianas) quanto discretas (categóricas). — Xu et al., § 4.5 TVAE Model

Codificador

class Encoder(Module):
    def __init__(self, data_dim, compress_dims, embedding_dim):
        super(Encoder, self).__init__()
        dim = data_dim
        seq = []
        for item in list(compress_dims):
            seq += [Linear(dim, item), ReLU()]
            dim = item
        self.seq = Sequential(*seq)
        self.fc1 = Linear(dim, embedding_dim)   # μ
        self.fc2 = Linear(dim, embedding_dim)   # log σ²

    def forward(self, input_):
        feature = self.seq(input_)
        mu = self.fc1(feature)
        logvar = self.fc2(feature)
        std = torch.exp(0.5 * logvar)
        return mu, std, logvar

class Decoder(Module):
    def __init__(self, embedding_dim, decompress_dims, data_dim):
        super(Decoder, self).__init__()
        dim = embedding_dim
        seq = []
        for item in list(decompress_dims):
            seq += [Linear(dim, item), ReLU()]
            dim = item
        seq.append(Linear(dim, data_dim))
        self.seq = Sequential(*seq)
        self.sigma = Parameter(torch.ones(data_dim) * 0.1)

    def forward(self, input_):
        return self.seq(input_), self.sigma

ctgan/synthesizers/tvae.py linhas 79–103 — _loss_function() 
def _loss_function(recon_x, x, sigmas, mu, logvar, output_info, factor):
    st = 0
    loss = []
    for column_info in output_info:
        for span_info in column_info:
            if span_info.activation_fn != 'softmax':
                # Contínuo: log-verossimilhança negativa Gaussiana
                ed = st + span_info.dim
                std = sigmas[st]
                eq = x[:, st] - torch.tanh(recon_x[:, st])
                loss.append((eq**2 / 2 / (std**2)).sum())
                loss.append(torch.log(std) * x.size()[0])
                st = ed
            else:
                # Discreto: entropia cruzada
                ed = st + span_info.dim
                loss.append(cross_entropy(
                    recon_x[:, st:ed],
                    torch.argmax(x[:, st:ed], dim=-1),
                    reduction='sum'
                ))
                st = ed

    KLD = -0.5 * torch.sum(1 + logvar - mu**2 - logvar.exp())
    return sum(loss) * factor / x.size()[0], KLD / x.size()[0]

Conclusões Principais
  • O Gerador Condicional é o componente mais crítico (-36,5% quando removido).
  • A normalização MinMax causa degradação severa (-25,7%) — a normalização por modos é essencial.
  • O Treinamento por Amostragem melhora o desempenho em 17,8% em relação ao treinamento ingênuo.
  • O WGAN-GP fornece um ganho modesto de +1,75% em relação à perda padrão da GAN.
