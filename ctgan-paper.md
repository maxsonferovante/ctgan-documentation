# Modeling Tabular Data using Conditional GAN

Lei Xu (MIT LIDS), Maria Skoularidou (University of Cambridge), Alfredo Cuesta-Infante (Universidad Rey Juan Carlos), Kalyan Veeramachaneni (MIT LIDS)

arXiv:1907.00503v2 [cs.LG] 28 Oct 2019

## Abstract

Modeling the probability distribution of rows in tabular data and generating realistic synthetic data is a non-trivial task. Tabular data usually contains a mix of discrete and continuous columns. Continuous columns may have multiple modes whereas discrete columns are sometimes imbalanced making the modeling difficult. Existing statistical and deep neural network models fail to properly model this type of data. We design CTGAN, which uses a conditional generator to address these challenges. To aid in a fair and thorough comparison, we design a benchmark with 7 simulated and 8 real datasets and several Bayesian network baselines. CTGAN outperforms Bayesian methods on most of the real datasets whereas other deep learning methods could not.

## 1 Introduction

Recent developments in deep generative models have led to a wealth of possibilities. Using images and text, these models can learn probability distributions and draw high-quality realistic samples. Over the past two years, the promise of such models has encouraged the development of generative adversarial networks (GANs) for tabular data generation. GANs offer greater flexibility in modeling distributions than their statistical counterparts.

We found that modeling tabular data poses unique challenges for GANs, causing them to fall short of the baseline methods on a number of metrics such as likelihood fitness and machine learning efficacy of the synthetically generated data.

### Contributions

1. **Conditional GANs for synthetic data generation.** We propose CTGAN as a synthetic tabular data generator. CTGAN outperforms all methods to date and surpasses Bayesian networks on at least 87.5% of our datasets. We also adapt a variational autoencoder (VAE) for mixed-type tabular data generation called TVAE.

2. **A benchmarking system for synthetic data generation algorithms.** Our benchmark uses several tabular datasets and different evaluation metrics as well as implementations of several baselines and state-of-the-art methods.

## 2 Related Work

During the past decade, synthetic data has been generated by treating each column in a table as a random variable, modeling a joint multivariate probability distribution, and then sampling from that distribution. For example, discrete variables may have been modeled using decision trees and Bayesian networks. Spatial data could be modeled with a spatial decomposition tree. Non-linearly correlated continuous variables could be modeled using copulas.

The development of generative models using VAEs and GANs has been very appealing due to the performance and flexibility offered. GANs are also used in generating tabular data, especially healthcare records.

## 3 Challenges with GANs in Tabular Data Generation Task

The task requires training a data synthesizer G learnt from a table T and then using G to generate a synthetic table T_syn.

### Key Challenges

1. **Mixed data types.** Real-world tabular data consists of mixed types. GANs must apply both softmax and tanh on the output to simultaneously generate discrete and continuous columns.

2. **Non-Gaussian distributions.** In images, pixels' values follow a Gaussian-like distribution. Continuous values in tabular data are usually non-Gaussian where min-max transformation will lead to vanishing gradient problem.

3. **Multimodal distributions.** 57/123 continuous columns in our 8 real-world datasets have multiple modes. Vanilla GAN couldn't model all modes on a simple 2D dataset.

4. **Learning from sparse one-hot-encoded vectors.** A trivial discriminator can distinguish real and fake data by checking the distribution's sparseness instead of considering the overall realness of a row.

5. **Highly imbalanced categorical columns.** 636/1048 of the categorical columns are highly imbalanced (major category >90%). This creates severe mode collapse.

## 4 CTGAN Model

CTGAN is a GAN-based method to model tabular data distribution and sample rows from the distribution.

### 4.1 Notations

- x₁ ⊕ x₂ ⊕ ... : concatenate vectors
- gumbel_τ(x): apply Gumbel softmax with parameter τ
- leaky_γ(x): apply leaky ReLU with leaky ratio γ
- FC_{u→v}(x): apply linear transformation on u-dim input to get v-dim output

### 4.2 Mode-specific Normalization

Each column is processed independently. Each value is represented as a one-hot vector indicating the mode, and a scalar indicating the value within the mode. Three steps:

1. For each continuous column Cᵢ, use variational Gaussian mixture model (VGM) to estimate the number of modes mᵢ and fit a Gaussian mixture:
   P_{Cᵢ}(cᵢ,ⱼ) = Σₖ μₖ N(cᵢ,ⱼ; ηₖ, ϕₖ)

2. For each value cᵢ,ⱼ in Cᵢ, compute the probability of cᵢ,ⱼ coming from each mode:
   ρₖ = μₖ N(cᵢ,ⱼ; ηₖ, ϕₖ)

3. Sample one mode from the probability density, and use the sampled mode to normalize the value:
   - One-hot vector βᵢ,ⱼ indicating the mode
   - Scalar αᵢ,ⱼ = (cᵢ,ⱼ - η₃) / (4ϕ₃) representing value within the mode

Row representation becomes:
rⱼ = α₁,ⱼ ⊕ β₁,ⱼ ⊕ ... ⊕ α_{Nc},ⱼ ⊕ β_{Nc},ⱼ ⊕ d₁,ⱼ ⊕ ... ⊕ d_{Nd},ⱼ

### 4.3 Conditional Generator and Training-by-Sampling

**Conditional vector:** A vector cond indicating the condition (D_{i*} = k*). All discrete columns become one-hot vectors d₁, ..., d_{Nd}. Mask vectors mᵢ are used to express the condition.

**Generator loss:** Penalizes by adding cross-entropy between m_{i*} and d̂_{i*}.

**Training-by-sampling steps:**
1. Create N_d zero-filled mask vectors mᵢ
2. Randomly select a discrete column Dᵢ with equal probability
3. Construct PMF using log-frequency of each category
4. Randomly select value k* according to the PMF
5. Set m_{i*}^{(k*)} = 1
6. Calculate cond = m₁ ⊕ ... ⊕ m_{Nd}

### 4.4 Network Structure

Fully-connected networks in generator and critic. Two hidden layers in both.

**Generator G(z, cond):**
- h₀ = z ⊕ cond
- h₁ = h₀ ⊕ ReLU(BN(FC_{|cond|+|z|→256}(h₀)))
- h₂ = h₁ ⊕ ReLU(BN(FC_{|cond|+|z|+256→256}(h₁)))
- α̂ᵢ = tanh(FC_{|cond|+|z|+512→1}(h₂))  for 1≤i≤Nc
- β̂ᵢ = gumbel_{0.2}(FC_{|cond|+|z|+512→mᵢ}(h₂))  for 1≤i≤Nc
- d̂ᵢ = gumbel_{0.2}(FC_{|cond|+|z|+512→|Dᵢ|}(h₂))  for 1≤i≤Nd

**Critic C(r₁, ..., r₁₀, cond₁, ..., cond₁₀):**
- h₀ = r₁ ⊕ ... ⊕ r₁₀ ⊕ cond₁ ⊕ ... ⊕ cond₁₀
- h₁ = drop(leaky_{0.2}(FC_{10|r|+10|cond|→256}(h₀)))
- h₂ = drop(leaky_{0.2}(FC_{256→256}(h₁)))
- C(·) = FC_{256→1}(h₂)

Uses PacGAN framework with pac size 10. Trained using WGAN loss with gradient penalty. Adam optimizer with learning rate 2·10⁻⁴.

### 4.5 TVAE Model

Adapts VAE to tabular data using the same preprocessing and modified loss function.

**Decoder p_θ(rⱼ|zⱼ):**
- h₁ = ReLU(FC_{128→128}(zⱼ))
- h₂ = ReLU(FC_{128→128}(h₁))
- ᾱᵢ,ⱼ = tanh(FC_{128→1}(h₂))  for 1≤i≤Nc
- α̂ᵢ,ⱼ ~ N(ᾱᵢ,ⱼ, δᵢ)  for 1≤i≤Nc
- β̂ᵢ,ⱼ ~ softmax(FC_{128→mᵢ}(h₂))  for 1≤i≤Nc
- d̂ᵢ,ⱼ ~ softmax(FC_{128→|Dᵢ|}(h₂))  for 1≤i≤Nd

**Encoder q_ϕ(zⱼ|rⱼ):**
- h₁ = ReLU(FC_{|rⱼ|→128}(rⱼ))
- h₂ = ReLU(FC_{128→128}(h₁))
- μ = FC_{128→128}(h₂)
- σ = exp(½ FC_{128→128}(h₂))
- q_ϕ(zⱼ|rⱼ) ~ N(μ, σI)

TVAE trained using Adam with learning rate 1e-3.

## 5 Benchmarking

### 5.1 Baselines and Datasets

**Baselines:** Bayesian networks (CLBN, PrivBN), deep learning approaches (MedGAN, VeeGAN, TableGAN)

**Datasets:** 7 simulated (Grid, GridR, Ring, Asia, Alarm, Child, Insurance) + 8 real (Adult, Census, Covertype, Credit, Intrusion, MNIST12, MNIST28, News)

### 5.2 Evaluation Metrics

- **Likelihood fitness:** Compute likelihood of T_syn on the oracle S
- **Machine learning efficacy:** Train prediction models on T_syn, test on T_test

## 6 Conclusion

We propose CTGAN for modeling tabular data distribution. Mode-specific normalization converts continuous values of arbitrary range and distribution into a bounded vector representation. The conditional generator and training-by-sampling overcome the imbalance training data issue. CTGAN outperforms Bayesian networks on most real datasets.
