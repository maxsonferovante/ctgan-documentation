CTGAN — Aprofundamento nos Transformadores RDT

Como o CTGAN usa o RDT (Reversible Data Transforms) para codificar dados reais em tensores compatíveis com GAN

▶ Processo de Normalização Completo

O que é o RDT?

RDT (Reversible Data Transforms) é uma biblioteca que fornece transformadores bidirecionais para dados tabulares. O CTGAN usa o ClusterBasedNormalizer do RDT para colunas contínuas e OneHotEncoder para colunas discretas. A ideia chave: o RDT torna as transformações reversíveis — você pode ir de dados reais → codificados → de volta aos dados reais com perda mínima de informação.

Função do RDT no pipeline do CTGAN
Dados Brutos → RDT.fit() (aprender parâmetros) → RDT.transform() (codificar) → Treinamento GAN → Geração GAN → RDT.inverse_transform() (decodificar) → Dados Sintéticos

ClusterBasedNormalizer — O Transformador Principal

1 Arquitetura e Parâmetros ▸ 
# rdt/transformers/numerical.py — ClusterBasedNormalizer
class ClusterBasedNormalizer(FloatFormatter):
    """Transformer for numerical data using a Bayesian Gaussian Mixture Model.

    This transformation takes a numerical value and transforms it using a Bayesian GMM
    model. It generates two outputs:
    1. A discrete value indicating the selected 'component' of the GMM
    2. A continuous value representing the normalized value based on mean and std
    """

    STD_MULTIPLIER = 4  # ← CONSTANTE CHAVE: ±4σ cobre 99.99% da distribuição normal
    _bgm_transformer = None
    valid_component_indicator = None

    def __init__(
        self,
        model_missing_values=None,
        learn_rounding_scheme=False,
        enforce_min_max_values=False,
        max_clusters=10,           # ← máx de componentes GMM
        weight_threshold=0.005,    # ← poda modos com peso < 0.5%
        missing_value_generation='random',
    ):
Parâmetros Principais
max_clusters=10: Número máximo de componentes GMM. O BayesianGMM pode usar menos.
weight_threshold=0.005: Componentes com peso < 0.5% são podados.
STD_MULTIPLIER=4: A normalização usa 4σ (não 1σ), então 99.99% dos valores ficam em [-1, 1].
missing_value_generation='random': Preenche NaN com valores aleatórios no range dos dados.
2 _fit() — Ajuste do GMM Bayesiano ▸ 
# rdt/transformers/numerical.py — _fit()
def _fit(self, data):
    sm = import_module('sklearn.mixture')

    self._bgm_transformer = sm.BayesianGaussianMixture(
        n_components=self.max_clusters,           # 10
        weight_concentration_prior_type='dirichlet_process',
        weight_concentration_prior=0.001,         # ← Prior Dirichlet (esparso)
        random_state=self._get_current_random_seed(),
    )

    super()._fit(data)                              # FloatFormatter._fit
    data = super()._transform(data)                 # FloatFormatter._transform
    if data.ndim > 1:
        data = data[:, 0]                           # extrai coluna numérica

    with warnings.catch_warnings():
        warnings.simplefilter('ignore')
        self._bgm_transformer.fit(data.reshape(-1, 1))  # ajusta GMM na coluna

    # Poda de modos com peso < threshold
    self.valid_component_indicator = (
        self._bgm_transformer.weights_ > self.weight_threshold
    )
O que o BayesianGaussianMixture faz internamente
1. Prior de Processo de Dirichlet:
  weight_concentration_prior=0.001 significa que o modelo prefere fortemente menos componentes.
  É por isso que 10 componentes podem encolher para 2-3 após o ajuste.

2. Algoritmo EM (Expectation-Maximization):
  E-step: Calcula responsabilidades r(i,k) = P(componente=k | xᵢ)
  M-step: Atualiza μₖ, Σₖ, πₖ usando estatísticas ponderadas
  Repete até convergência

3. Poda:
  Após o ajuste, modos com πₖ < 0.005 são marcados como inválidos.
  Apenas modos válidos são usados para normalização.
3 _transform() — Seleção de Modo + Normalização ▸ 
# rdt/transformers/numerical.py — _transform()
def _transform(self, data):
    data = super()._transform(data)          # lida com nulos
    if data.ndim > 1:
        data, model_missing_values = data[:, 0], data[:, 1]

    data = data.reshape((len(data), 1))      # (n, 1)

    # Obtém parâmetros dos modos
    means = self._bgm_transformer.means_.reshape((1, self.max_clusters))
    means = means[:, self.valid_component_indicator]     # (1, n_modos_válidos)
    stds = np.sqrt(self._bgm_transformer.covariances_).reshape((1, self.max_clusters))
    stds = stds[:, self.valid_component_indicator]       # (1, n_modos_válidos)

    # ── NORMALIZAÇÃO ──
    # Multiplica stds por 4 para que o valor fique em [-1,1] com 99.99% de probabilidade
    normalized_values = (data - means) / (self.STD_MULTIPLIER * stds)

    # ── SELEÇÃO DE MODO ──
    component_probs = self._bgm_transformer.predict_proba(data)
    component_probs = component_probs[:, self.valid_component_indicator]

    selected_component = np.zeros(len(data), dtype='int')
    for i in range(len(data)):
        component_prob_t = component_probs[i] + 1e-6          # evita divisão por zero
        component_prob_t = component_prob_t / component_prob_t.sum()  # normaliza
        selected_component[i] = np.random.choice(
            np.arange(self.valid_component_indicator.sum()),
            p=component_prob_t,                                # amostra das probabilidades
        )

    # Extrai valor normalizado para o modo selecionado
    aranged = np.arange(len(data))
    normalized = normalized_values[aranged, selected_component].reshape([-1, 1])
    normalized = np.clip(normalized, -0.99, 0.99)             # recorta para range seguro

    return np.stack([normalized[:, 0], selected_component], axis=1)
Formulação matemática — Artigo § 4.2
Dados: valor c, modo k com parâmetros (μₖ, ϕₖ)

Transformação direta:
α = (c − μₖ) / (4 × ϕₖ)
  onde 4 × ϕₖ garante que α ∈ [-1, 1] com 99.99% de probabilidade

Seleção de modo (probabilística):
P(C=k | c) = πₖ × N(c; μₖ, ϕₖ) / Σⱼ πⱼ × N(c; μⱼ, ϕⱼ)
selected_component ~ Categorical(P(C|c))

Saída: [α, selected_component] por linha

Por que seleção probabilística de modo?

Em vez de atribuição dura (argmax), o RDT amostra da distribuição de probabilidade. Isso adiciona estocasticidade que ajuda o GAN a aprender transições entre modos. Um valor próximo à fronteira entre dois modos será atribuído aleatoriamente a um deles.

4 _reverse_transform_helper() — Mapeamento Inverso ▸ 
# rdt/transformers/numerical.py — _reverse_transform_helper()
def _reverse_transform_helper(self, data):
    normalized = np.clip(data[:, 0], -1, 1)          # α ∈ [-1, 1]

    means = self._bgm_transformer.means_.reshape([-1])
    stds = np.sqrt(self._bgm_transformer.covariances_).reshape([-1])

    selected_component = data[:, 1].round().astype(int)    # índice do modo discreto
    selected_component = selected_component.clip(
        0, self.valid_component_indicator.sum() - 1         # garante range válido
    )

    std_t = stds[self.valid_component_indicator][selected_component]
    mean_t = means[self.valid_component_indicator][selected_component]

    # ── NORMALIZAÇÃO INVERSA ──
    reversed_data = normalized * self.STD_MULTIPLIER * std_t + mean_t
    # α × 4 × ϕₖ + μₖ = valor original

    return reversed_data
Fórmula da transformação inversa
Dados: α (normalizado), modo k

c = α × 4 × ϕₖ + μₖ

Exemplo:
α = 0.711, modo 0 (μ₀=1935, ϕ₀=2345)
c = 0.711 × 4 × 2345 + 1935
c = 0.711 × 9380 + 1935
c = 6669.18 + 1935 = 8.604

Comportamento de clipping

O α de entrada é cortado para [-1, 1]. Isso significa que valores gerados fora do range de treino são limitados. Por exemplo, se o range de treino do balance era [-230, 67200], um α = 1.2 seria cortado para 1.0, produzindo o valor máximo possível.

GaussianNormalizer — Transformador Alternativo

5 Normalização baseada em Cópula (CDF + Inversa CDF) ▸
Artigo § 3.3 — Transformação de cópula
Dada uma variável x:
1. Encontrar a melhor distribuição marginal: P(x)
2. Calcular: u = Φ(x) onde Φ é a CDF de P(x)
3. Calcular: z = Φ⁻¹_N(0,1)(u) onde Φ⁻¹ é a inversa CDF da normal padrão

Resultado: z ~ N(0, 1) independentemente da distribuição original 
# rdt/transformers/numerical.py — GaussianNormalizer
class GaussianNormalizer(FloatFormatter):
    """Transformer for numerical data based on copulas transformation.

    Transformation consists on bringing the input data to a standard normal space
    by using a combination of *cdf* and *inverse cdf* transformations.
    """

    def _copula_transform(self, data):
        cdf = self._univariate.cdf(data)          # P(x) → u ∈ [0, 1]
        return scipy.stats.norm.ppf(
            cdf.clip(0 + EPSILON, 1 - EPSILON)    # recorta para evitar ±inf
        )                                          # Φ⁻¹(u) → z ~ N(0,1)

    def _reverse_transform(self, data):
        if data.ndim > 1:
            data[:, 0] = self._univariate.ppf(    # Φ⁻¹ da marginal
                scipy.stats.norm.cdf(data[:, 0])   # Φ da normal padrão → u
            )                                      # u → escala original
        else:
            data = self._univariate.ppf(
                scipy.stats.norm.cdf(data)
            )
        return super()._reverse_transform(data)
Exemplo numérico passo a passo
Dado: x = 12.450 com TruncatedNormal ajustada(μ=20000, σ=15000)

Passo 1: u = Φ_TruncNorm(12450) = 0.32 (CDF da normal truncada)
Passo 2: z = Φ⁻¹_N(0,1)(0.32) = -0.468 (inversa CDF da normal padrão)

Inversa:
Passo 1: u = Φ_N(0,1)(-0.468) = 0.32
Passo 2: x = Φ⁻¹_TruncNorm(0.32) = 12.450

# rdt/transformers/categorical.py — OneHotEncoder
class OneHotEncoder(BaseTransformer):
    """OneHotEncoding for categorical data.

    This transformer replaces a single vector with N unique categories
    with N vectors which have 1s on the rows where the corresponding
    category is found and 0s on the rest.
    """

    def _fit(self, data):
        self.dtype = data.dtype
        data = self._prepare_data(data)

        null = pd.isna(data).to_numpy()
        self._uniques = list(pd.unique(data[~null]))     # ex: ['Checking', 'Savings']
        self._dummy_na = null.any()                       # True se houver NaN
        self._num_dummies = len(self._uniques)            # 2
        self._indexer = list(range(self._num_dummies))
        self.dummies = self._uniques.copy()

        if not np.issubdtype(data.dtype.type, np.number):
            self._dummy_encoded = True                    # categorias string

        if self._dummy_na:
            self.dummies.append(np.nan)                   # NaN recebe sua própria coluna

    def _transform_helper(self, data):
        if self._dummy_encoded:
            coder = self._indexer                          # [0, 1]
            codes = pd.Categorical(data, categories=self._uniques).codes
        else:
            coder = self._uniques
            codes = data

        rows = len(data)
        dummies = np.broadcast_to(coder, (rows, self._num_dummies))
        coded = np.broadcast_to(codes, (self._num_dummies, rows)).T
        array = (coded == dummies).astype(int)             # matriz one-hot

        if self._dummy_na:
            null = np.zeros((rows, 1), dtype=int)
            null[pd.isna(data)] = 1
            array = np.append(array, null, axis=1)

        return array

    def _reverse_transform(self, data):
        indices = np.argmax(data, axis=1)                 # seleciona coluna com valor máx
        result = pd.Series(indices).map(self.dummies.__getitem__)
        return result

NullTransformer — Tratamento de Valores Ausentes

7 Três estratégias para valores ausentes ▸ 
# rdt/transformers/null.py — NullTransformer
class NullTransformer:
    """Transformer for data that contains Null values.

    Args:
        missing_value_replacement: 'mean' | 'mode' | 'random' | float | None
        missing_value_generation: 'random' | 'from_column' | None
    """

    def fit(self, data):
        self._missing_value_replacement = self._get_missing_value_replacement(data)
        if self._missing_value_replacement == 'random':
            self._min_value = data.min()
            self._max_value = data.max()

        if self._missing_value_generation is not None:
            null_values = data.isna().to_numpy()
            self.nulls = null_values.any()
            if self._missing_value_generation == 'random':
                self._null_percentage = null_values.sum() / len(data)

    def transform(self, data):
        isna = data.isna()
        if self._missing_value_replacement == 'random':
            # Preenche NaN com valores aleatórios no range [min, max]
            data_mask = list(
                np.random.uniform(low=self._min_value, high=self._max_value, size=len(data))
            )
            data = data.mask(data.isna(), data_mask)
        elif isna.any() and self._missing_value_replacement is not None:
            data = data.infer_objects().fillna(self._missing_value_replacement)

        if self._missing_value_generation == 'from_column':
            return pd.concat([data, isna.astype(np.float64)], axis=1).to_numpy()
        return data.to_numpy()

    def reverse_transform(self, data):
        data = data.copy()
        if self._missing_value_generation == 'from_column':
            if self.nulls:
                isna = data[:, 1] > 0.5              # threshold na coluna indicadora
            data = data[:, 0]
        elif self.nulls:
            isna = np.random.random((len(data),)) < self._null_percentage

        data = pd.Series(data)
        if self.nulls and isna.any():
            data.loc[isna] = np.nan
        return data
Comparação de estratégias para valores ausentes
'random': Preenche NaN com aleatório uniforme(data.min, data.max). Inversa: aleatoriamente restaura NaN com a mesma porcentagem.
'from_column': Cria coluna indicadora binária. Inversa: onde indicador > 0.5, define NaN.
None: Sem tratamento. Inversa: passa direto (dados podem conter NaN).
EstratégiaTransformaçãoInversaPerda Info

'from_column'Adiciona coluna bináriaUsa coluna > 0.5 como máscaraBaixa

FloatFormatter — Transformador Base

8 Arredondamento, imposição de min/máx, tratamento de dtype ▸ 
# rdt/transformers/numerical.py — FloatFormatter
class FloatFormatter(BaseTransformer):
    """Transformer for numerical data.

    This transformer replaces integer values with their float equivalent.
    Non null float values are not modified.
    """

    def _fit(self, data):
        self._dtype = data.dtype

        if self.enforce_min_max_values:
            self._min_value = data.min()
            self._max_value = data.max()

        if self.learn_rounding_scheme:
            self._rounding_digits = learn_rounding_digits(data)

        self.null_transformer = NullTransformer(
            self.missing_value_replacement, self.missing_value_generation
        )
        self.null_transformer.fit(data)

    def _reverse_transform(self, data):
        data = self.null_transformer.reverse_transform(data)

        if self.enforce_min_max_values:
            data = data.clip(self._min_value, self._max_value)
        elif not self.computer_representation.startswith('Float'):
            min_bound, max_bound = INTEGER_BOUNDS[self.computer_representation]
            data = data.clip(min_bound, max_bound)

        is_integer = pd.api.types.is_integer_dtype(self._dtype)
        if self.learn_rounding_scheme and self._rounding_digits is not None:
            data = data.round(self._rounding_digits)
        elif is_integer:
            data = data.round(0)

        return data.astype(self._dtype)
Algoritmo learn_rounding_digits
Entrada: série de dados
1. Encontrar o maior inteiro absoluto nos dados
2. most_digits = len(str(max_abs))
3. max_decimals = max(0, MAX_DECIMALS - most_digits)
4. Para decimal em 0..max_decimals:
  se data == data.round(decimal) para todos os valores:
    retornar decimal
5. retornar None (não pode arredondar)

# rdt/transformers/numerical.py — LogitScaler
class LogitScaler(FloatFormatter):
    """Transformer for numerical data by applying a logit function.

    This transformer works by replacing the values with a scaled
    version and then applying a logit function. The reverse transform
    applies a sigmoid to the data and then scales it back.
    """

    def __init__(self, min_value=0.0, max_value=1.0, ...):
        self.min_value = min_value
        self.max_value = max_value

    def _transform(self, data):
        transformed = super()._transform(data)
        logit_vals = logit(transformed[:, 0], self.min_value, self.max_value)
        return transformed

    def _reverse_transform(self, data):
        reversed_values = sigmoid(sampled_vals, self.min_value, self.max_value)
        return super()._reverse_transform(reversed_values)
Fórmulas Logit e Sigmoid rdt/transformers/utils.py
Função Logit: logit(x, low, high)
1. x_scaled = (x - low) / (high - low)   ← normaliza para [0, 1]
2. x_scaled = x_scaled × 0.95 + 0.025   ← mapeia para [0.025, 0.975] (evita ±inf)
3. resultado = ln(x_scaled / (1 - x_scaled))   ← logit padrão

Função Sigmoid: sigmoid(x, low, high)
1. x_sigmoid = 1 / (1 + exp(-x))   ← sigmoid padrão → [0, 1]
2. x_scaled = (x_sigmoid - 0.025) / 0.95   ← desfaz o escalonamento 0.95
3. resultado = x_scaled × (high - low) + low   ← desfaz a normalização

Exemplo numérico

Dado: x = 0.65, low = 0.0, high = 1.0

Logit:
x_scaled = (0.65 - 0) / (1.0 - 0) = 0.65
x_scaled = 0.65 × 0.95 + 0.025 = 0.6425
logit = ln(0.6425 / (1 - 0.6425)) = ln(1.797) = 0.586

Sigmoid (inversa):
sigmoid = 1 / (1 + exp(-0.586)) = 1 / (1 + 0.556) = 0.6425
x_scaled = (0.6425 - 0.025) / 0.95 = 0.65
resultado = 0.65 × (1.0 - 0.0) + 0.0 = 0.65 ✓

LogScaler — Transformação Logarítmica

10 Normalização baseada em log para dados positivos/enviesados ▸ 
# rdt/transformers/numerical.py — LogScaler
class LogScaler(FloatFormatter):
    """Transformer for numerical data using log.

    Args:
        constant: The constant to set as the 0-value for the log. Defaults to 0.
        invert: Whether to invert the data with respect to the constant.
                If False: all values > constant (positive skew).
                If True: all values < constant (negative skew).
    """

    def _log_transform(self, data):
        if self.invert:
            return np.log(self.constant - data)   # para enviesamento negativo
        else:
            return np.log(data - self.constant)    # para enviesamento positivo

    def _reverse_log(self, data):
        if self.invert:
            return self.constant - np.exp(data)    # desfaz invert
        else:
            return np.exp(data) + self.constant    # desfaz
Fórmulas da transformação log
Padrão (invert=False):
transformação: y = ln(x - constante)
inversa: x = exp(y) + constante

Invertida (invert=True):
transformação: y = ln(constante - x)
inversa: x = constante - exp(y)

Exemplo: constante=0, x=100
y = ln(100) = 4.605
x = exp(4.605) = 100 ✓

Gerenciamento de Estado Aleatório

11 Reprodutibilidade Determinística no RDT ▸ 
# rdt/transformers/base.py — gerenciamento de estado aleatório
class BaseTransformer:
    INITIAL_FIT_STATE = np.random.RandomState(42)

    def _set_seed(self, data):
        # Semente baseada no nome da coluna + primeiros 5 valores (determinístico!)
        hash_value = self.columns[0]
        for _, row in data.head(5).iterrows():
            hash_value += str(row[self.columns[0]])

        hash_value = int(hashlib.sha256(hash_value.encode('utf-8')).hexdigest(), 16)
        self.random_seed = hash_value % ((2**32) - 1)
        self.random_states = {
            'fit': self.INITIAL_FIT_STATE,
            'transform': np.random.RandomState(self.random_seed),
            'reverse_transform': np.random.RandomState(self.random_seed + 1),
        }
Como as sementes funcionam
1. Nome da coluna + primeiros 5 valores → hash SHA-256 → semente
2. Isso garante que a mesma coluna sempre recebe a mesma semente
3. Sementes separadas para fit/transform/reverse_transform
4. Permite transformações reproduzíveis mesmo com aleatoriedade

# ctgan/data_transformer.py — DataTransformer
class DataTransformer:
    """Transformers are fitted to the data and used to transform it."""

    def fit(self, data, discrete_columns):
        self._column_transform_info_list = []

        for column_name in data.columns:
            if column_name in discrete_columns:
                # ── DISCRETO: OneHotEncoder ──
                ht = OneHotEncoder()
                ht.fit(data, column_name)
                info = ColumnTransformInfo(
                    column_name=column_name,
                    column_type='discrete',
                    transform=ht,
                    output_info=[SpanInfo(ht._num_dummies, 'softmax')],
                    output_dimensions=ht._num_dummies,
                )
            else:
                # ── CONTÍNUO: ClusterBasedNormalizer ──
                gm = ClusterBasedNormalizer(
                    missing_value_generation='from_column',
                    max_clusters=min(len(data), self._max_clusters),
                    weight_threshold=self._weight_threshold,
                )
                gm.fit(data, column_name)
                num_components = sum(gm.valid_component_indicator)
                info = ColumnTransformInfo(
                    column_name=column_name,
                    column_type='continuous',
                    transform=gm,
                    output_info=[
                        SpanInfo(1, 'tanh'),                        # α escalar
                        SpanInfo(num_components, 'softmax'),         # one-hot do modo
                    ],
                    output_dimensions=1 + num_components,
                )

            self._column_transform_info_list.append(info)

        self.output_dimensions = sum(
            info.output_dimensions for info in self._column_transform_info_list
        )
Lógica de seleção de transformação RDT
Coluna contínua:
  Transformador: ClusterBasedNormalizer
  Saída: [α (tanh), β₀ (softmax), β₁ (softmax), ...]
  Dimensões: 1 + n_modos_válidos

Coluna discreta:
  Transformador: OneHotEncoder
  Saída: [vetor one-hot]
  Dimensões: n_categorias

# ctgan/data_transformer.py — inverse_transform()
def inverse_transform(self, data, sigmas=None):
    """Convert transformed data back to original format."""
    st = 0
    recovered = []

    for column_transform_info in self._column_transform_info_list:
        dim = column_transform_info.output_dimensions
        column_data = data[:, st:st+dim]

        if column_transform_info.column_type == 'continuous':
            recovered.append(
                self._inverse_transform_continuous(column_transform_info, column_data, sigmas, st)
            )
        else:
            recovered.append(
                self._inverse_transform_discrete(column_transform_info, column_data)
            )
        st += dim

    return np.column_stack(recovered)

def _inverse_transform_continuous(self, column_transform_info, column_data, sigmas, st):
    gm = column_transform_info.transform
    data = pd.DataFrame(
        column_data[:, :2],
        columns=['normalized', 'component']
    ).astype(float)
    data['component'] = np.argmax(column_data[:, 1:], axis=1)  # one-hot → índice

    # Opcional: adiciona ruído para diversidade
    if sigmas is not None:
        mean = np.zeros(len(data))
        std = sigmas + st
        mean = mean + std
        noise = np.random.normal(mean)
        data['normalized'] += noise

    return gm.reverse_transform(data)

def _inverse_transform_discrete(self, column_transform_info, column_data):
    ohe = column_transform_info.transform
    data = pd.DataFrame(column_data, columns=list(ohe.get_output_sdtypes()))
    return ohe.reverse_transform(data)[column_transform_info.column_name]
Fluxo completo do inverse_transform
Para cada coluna em output_info_list:
  se contínua:
    1. Extrair [α, β₀, β₁, ...] da saída sintética
    2. argmax(β₀, β₁, ...) → modo_selecionado
    3. gm.reverse_transform([α, modo_selecionado])
      → c = α × 4 × ϕₖ + μₖ
    4. Aplicar arredondamento se learn_rounding_scheme=True
    5. Recortar para [min_value, max_value] se enforce_min_max_values=True

  se discreta:
    1. argmax(vetor_one_hot) → índice_da_categoria
    2. categorias[índice_da_categoria] → string da categoria original

Insight Principal: O RDT é a ponte entre dados tabulares brutos e tensores compatíveis com GAN. O ClusterBasedNormalizer usa GMM + normalização 4σ para mapear qualquer distribuição para [-1, 1], enquanto o OneHotEncoder lida com colunas discretas. A reversibilidade dessas transformações é o que torna os dados sintéticos do CTGAN tão realistas.
